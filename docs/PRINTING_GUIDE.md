## 1. Zero-Screenshot Print Architecture

Traditional web printing attempts to screenshot DOM canvases or use `window.print()` directly on active viewports, resulting in clipped tables, scrollbar artifacts, and distorted fonts.

SliceMart FMS utilizes an **isolated DOM mount portal (`#print-root`)**:

1. When printing is requested, the targeted document component is mounted inside `#print-root`.
2. Dedicated physical `@page` CSS stylesheets are applied (`src/styles/print.css`).
3. Browser viewport styles, navigation bars, sidebars, and application shell elements are hidden via `@media print`.
4. High-contrast, vector-sharp typography and native SVG barcodes are rendered at device DPI.

## 2. Printer Types & Output Calibration

### 2.1 Standard Office & Warehouse Laser / Inkjet Printers

- **Target Sizes:** ISO A4 (210 × 297 mm), ISO A5, ISO A3, US Letter (8.5 × 11 in).
- **Recommended Media:** 80–120 GSM commercial bond paper.
- **Documents:** Sales Tax Invoices, Procurement Orders, Goods Receipt Notes, Delivery Challans, Stock Movement Manifests, Audit Reports.
- **Page Rules:** Multi-page table headers (`<thead>`) repeat automatically on subsequent pages. Page counters (`Page X of Y`) are generated by print margins.

### 2.2 Point-of-Sale (POS) Thermal Roll Printers

- **Target Sizes:** 80mm Continuous Thermal Roll, 58mm Compact Roll.
- **Target Printers:** Epson TM-T88 / TM-T20, Bixolon, Star Micronics, Rongta, Citizen.
- **Documents:** POS Cash Register Counter Receipts, Shift Summary Slips.
- **Page Rules:** Margin: 2mm top/bottom, 3mm left/right. High contrast monochromatic mode enabled.

### 2.3 Thermal Barcode Sticker & Label Printers

- **Target Sizes:** 50 × 35 mm Product Label, 35 × 25 mm Shelf Tag, A4 Multi-label Sheets (24/30-up).
- **Target Printers:** Zebra ZD220 / ZD420, TSC TE244 / TTP-244, Honeywell, Godex, Xprinter.
- **Documents:** Finished Goods Barcodes, Raw Material Batch Tags, Master Carton Shipping Labels.
- **Resolution:** 203 DPI (8 dots/mm) and 300 DPI (12 dots/mm) vector SVG rendering.

## 3. Configuring Print Profiles

1. Navigate to **Settings → Documents & Printing → Print Profiles**.
2. Click **New Profile** (e.g. *"Main Billing Counter Thermal"*).
3. Select the physical paper size (e.g. *80mm POS Thermal Roll*).
4. Set default print orientation (Portrait/Landscape) and color mode (Monochrome for thermal heads).
5. Link this profile to specific document templates for seamless 1-click printing without manual browser print dialog adjustments.
